1. Power grid

Given a grid of H rows and W columns. (i,j) denotes the cell at ith row and jth
column. You are given H string S1, S2 ..... SH which describes as follows:

. if jth character of Si is 'C`, then there is a transformer at (i,j)

. If jth character of Si is 'A`, then there is a relay at (i, j)

. If jth character of Si is '.`, then there is NOTHING at (i,j)

Both the transformer and relay can only pass electricity to the neighbor located to its right
or below (which could be either a transformer or a relay). The main station is connected to
(1,1) and the city main line is connected to (H,W). Electricity can flow from (1, 1) to
(H,W) in any way possible. Every time electricity is passed through a transformer, its
voltage changes. You want a steady voltage in the city.

Formally, the number of transformers in any possible path to (H, W) from (1, 1) should be
the same after filling the empty cells. We just need to ensure that the voltage supply is
steady at the city (H, W) only

Find the number of ways of filling up the empty cells with either a transformer or a relay in such a way that for each configuration, the voltage received at the city would be the same irrespective of the choice of the path.

Notes

· All transformers are identical.
· All empty cells must be filled to be considered a valid configuration
· All paths are independent of each other.
· Return the answer modulo 10^9 +7

Hint: For a given i and j, 1 <= i <= H and 1 <=j <= W values with i+j should have the same
type, which means either all should be a transformer or all should be a relay

code: def solution(H, W, S):
    MOD = 10**9 + 7
    
    # Create a grid to track the type of each cell
    type_grid = [[None] * W for _ in range(H)]
    
    # Fill the type_grid based on input
    for i in range(H):
        for j in range(W):
            if S[i][j] == 'C':
                type_grid[i][j] = 'C'
            elif S[i][j] == 'A':
                type_grid[i][j] = 'A'
            else:
                type_grid[i][j] = None  # Empty cell

    # Determine the number of configurations
    configurations = 1
    
    # Check each diagonal (i + j)
    for d in range(H + W - 1):
        # Track the type of the first cell in this diagonal
        current_type = None
        for i in range(max(0, d - W + 1), min(H, d + 1)):
            j = d - i
            if 0 <= j < W:
                if type_grid[i][j] is not None:
                    if current_type is None:
                        current_type = type_grid[i][j]
                    elif current_type != type_grid[i][j]:
                        # If we encounter a different type, we cannot fill this diagonal consistently
                        return 0
        
        # If the diagonal is empty, we can fill it in 2 ways (either all 'C' or all 'A')
        if current_type is None:
            configurations = (configurations * 2) % MOD
    
    return configurations
