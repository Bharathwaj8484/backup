Student's Height
Problem Statement
There are n students standing in a line. For each student, they can see only the next student ahead of them whose height is strictly greater than their own. If there is no taller student ahead, they see 0. The heights of students are given in the form of a singly linked list, where the head of the list represents the first student in the line.
Your task is to find the sum of all the heights seen by every student.
Input Format
• The first line contains an integer n, the number of students.
• The next n lines contain integers h;, representing the heights of each student in order.
• These values will be used to create a singly linked list, where the first entered value is the head.
Constraints
・ 1<＝n <＝10^5
• 1<= hi < = 10^5

Output Format
• Return the sum of heights seen by every student.

Evaluation Parameters
Sample Input 1
6
3

6
Sample Output 1
22
Explanation
For the list [3,6, 2,4,2,6], the next greater elements are
[6,0,4,6,6,0]. Their sum is 6+0+4+6+6+0 = 22.
