Convertible Graph

Problem Statement
You are given a graph of n vertices and k edges. You have to tell whether the given graph can be converted to a LinkedList or not.
A graph is said to be a Linked List if
• There is no cycle in the graph
• The given graph is a connected graph.

You can convert a graph to a linked list by removing at most one edge from the graph.
Input Format
• The first line will contain an integer n, denoting the number of vertices.
• The second line will contain an integer k, denoting the number of edges.
• Next, k lines each will contain 2 space-separated integers x, and y, denoting that there is an edge from x to y.

Constraints
• 1 ≤ n ≤ 10^3
• 1 ≤ k ≤ 10^5
• 1 ≤x, y <= n

Output Format
• Return "Yes" (without quotes) if it can be converted to a Linked List, or else return "No" (without quotes).

Evaluation Parameters
Sample Input 1
3
2
1 2
2 3
Sample Output 1
Yes

Explanation
The graph 1 - 2 - 3 is already a valid linked list. It is connected and has no cycle.
